    パスワード生成

    詳しく設定

    同期・バックアップ

    暗号化されたファイルを書き出し、iCloud Drive などに保存して他の端末で読み込みます。読み込み時は内容をマージします（新しい方を採用）。

    他のパスワード管理へ移す

    Apple の「パスワード」や Google Chrome に読み込める CSV ファイルを書き出します。このファイルは暗号化されません。読み込んだらすぐに削除してください。

    アプリのバージョン

    Windows / Mac で、サーバーに一切つながらずに使える版です。ダウンロードしたファイルをブラウザ（Chrome / Edge 推奨）で開いて使います。

    危険な操作

    kizupass の使い方

    見たい項目をタップすると開きます。

    1. はじめて使う

    iPhone

    1. Safari で kizunajamjam.github.io/kizupass を開く。
    2. 下の共有ボタン（□に↑）→「ホーム画面に追加」。
    3. 以後はホーム画面のアイコンから開く。Safari のまま使うと、しばらく使わないとデータが消えることがあります。

    Windows / Mac

    1. ウェブ版の ⚙︎ →「PC用のファイル版をダウンロード」。
    2. ダウンロードした kizupass-offline.html を好きな場所に置き、Chrome か Edge で開く（ブックマークしておくと便利）。

    マスターパスワードを決める

    • 12文字以上。おすすめは関係のない単語を4〜5個つなげたもの（例：みかん-電車-青空-えんぴつ）。
    • 他のサイトで使っていないものにする。
    • 忘れると誰にも復元できません。紙に書いて家の安全な場所に保管するのがおすすめです。
    2. 2台目以降の端末で使う
    1. 1台目で ⚙︎ →「暗号化ファイルを書き出す」→ iCloud Drive に保存。
    2. 2台目で kizupass を開き、最初の画面で「バックアップファイルから始める」。
    3. 保存したファイルを選び、1台目と同じマスターパスワードを入力。
    3. ログインするとき
    1. kizupass を開いてロック解除。
    2. 上の検索欄にサービス名を入れる。
    3. 項目を開き、ユーザー名の「コピー」→ ログイン画面に貼り付け。
    4. パスワードの「コピー」→ 貼り付け（一覧の「コピー」ボタンならパスワードを直接コピー）。
    • URL を登録しておくと「開く」でそのサイトに飛べます。
    • 貼り付ける前に、アドレスバーの URL が本物か確認してください。
    • コピーしたパスワードは30秒後に消えます。他のアプリに切り替えても、1分以内に戻ればロックされません。
    4. 新しく登録するとき
    1. 右下の ＋ → サービス名・ユーザー名・URL を入力。
    2. 新しいサービスなら「パスワードを生成…」→「使う」。今使っているパスワードがあるならそれを入力。
    3. サイトで「使えない文字がある」「長すぎる」などと言われたら、もう一度「パスワードを生成…」で「記号あり」「短め」などを押して作り直す（次からそのサイトではその形で作ります）。
    4. 「保存」。新しいサービスは、保存してからサイトの登録画面に貼り付けると、途中で失敗してもパスワードが残ります。
    5. パスワードを変えていく

    使い回しや弱いパスワードは、サイトごとに1つずつ変える必要があります。

    1. 上の「要注意」を押すと、使い回し・弱いパスワードの項目だけが出ます。
    2. サイトにログインして、パスワード変更の画面を開く。
    3. kizupass でその項目を開き「パスワードを生成…」→「使う」（自動で「変更済み」にチェックが入ります）。
    4. パスワードを「コピー」してサイトの変更画面に貼り付け、変更を完了する。
    5. kizupass で「保存」。
    • 前のパスワードは残るので、サイト側で失敗しても戻せます。新しいパスワードでログインできたら「消す」で消して大丈夫です。
    • 優先して変えたいもの：メインのメール → Apple ID・Google → 銀行・カード・ショッピング → SNS。
    • 上のバーで「〇件中〇件 変更済み」と進み具合がわかります。
    6. 端末間で同期・バックアップ

    kizupass は自動では同期しません。登録や変更をしたら、次の手順で他の端末に反映してください。これがバックアップにもなります。

    1. 変更した端末で ⚙︎ →「暗号化ファイルを書き出す」→ iCloud Drive に保存（iPhone は共有シートの「"ファイル"に保存」）。
    2. 他の端末で ⚙︎ →「ファイルを読み込んでマージ」→ そのファイルを選ぶ。
    • 同じ項目は更新日時が新しい方が残り、削除した項目も反映されます。
    • ファイルは暗号化されているので、iCloud に置いても中身は読めません。
    7. Apple「パスワード」/ Chrome へ移す
    1. ⚙︎ →「他のパスワード管理へ移す」→ 移したい先を選ぶ。
    2. マスターパスワードを入力して CSV を保存。
    3. 表示される手順で読み込む。
    4. 読み込んだら CSV をすぐ削除（ゴミ箱からも）。暗号化されていないため、iCloud Drive やメールには置かないでください。

    URL が登録されていない項目は移せません（一覧で表示されます）。

    8. アプリの更新
    • ウェブ版：新しいバージョンがあると「新しいバージョンがあります」と出ます。「変更内容を見る」で内容を確認してから「更新する」。心当たりのない更新は押さないでください。
    • ファイル版：自動では更新されません。新しい機能を使いたいときは、ウェブ版の ⚙︎ からもう一度ダウンロードしてください。
    9. 困ったとき
    マスターパスワードを忘れた
    復元する方法はありません。各サイトの「パスワードを忘れた」から再設定し、kizupass を作り直してください。
    パスワードを間違えて待たされる
    3回続けて間違えると少し待つ必要があります。時間がたてばまた入力できます。
    データが消えた
    書き出したファイルがあれば「バックアップファイルから始める」で戻せます。
    勝手にロックされる
    安全のため、5分操作しないか、他のアプリに1分以上切り替えるとロックされます。
    ファイル版の保存がうまくいかない
    Safari ではなく Chrome か Edge で開いてください。
    10. 安全に使うために
    • GitHub アカウントに2段階認証を設定する（ウェブ版の配信元を守るため）。
    • 各サービス側でも2段階認証を有効にする。
    • 定期的に書き出してバックアップする。
    • kizupass は第三者の監査を受けていません。銀行など特に大事なものは、Apple の「パスワード」などとの併用がおすすめです。

      URL が登録されていないため、次の項目は書き出していません。URL を追加してもう一度書き出すか、手で移してください。
