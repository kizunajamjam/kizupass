# kizupass

iPhone・Windows・Mac で使える、自分専用のパスワード管理アプリ（PWA）。

- **完全無料**：App Store 登録やサーバー代は不要。静的ファイルを置くだけで動きます。
- **端末内で暗号化**：パスワードがネットに送られることはありません。
- **外部ライブラリは1つだけ**：Argon2id のための [hash-wasm](https://www.npmjs.com/package/hash-wasm)（MIT）をリポジトリに同梱。CDN からは読み込まず、ハッシュ値をテストで検証しています。
- **勝手に更新されない**：新しいバージョンは、利用者が内容を確認して「更新する」を押したときだけ反映されます。
- **オフラインで動作**：一度開けば、通信なしでも使えます。

## セキュリティの仕組み

| 項目 | 内容 |
| --- | --- |
| 鍵の導出 | Argon2id（メモリ 64MiB・3 回・並列 1）、ランダムソルト 16 バイト。GPU での総当たりに強い |
| 暗号化 | AES-256-GCM（保存のたびに新しい IV。鍵導出の設定も含めて改ざんを検出） |
| 鍵の扱い | エクスポート不可の `CryptoKey` としてメモリ上だけに保持。導出直後の生の鍵バイト列は消去。ロック時に破棄 |
| 自動ロック | 操作なしで 5 分後、バックグラウンドに回って 1 分後 |
| 総当たり対策 | 3 回続けて間違えると待ち時間（最大 60 秒）。根本的な対策は Argon2id の重さ |
| クリップボード | コピーから 30 秒後に自動消去（iPhone では効かない場合あり） |
| アプリの更新 | Service Worker が使用中のバージョンを固定。新版は事前にダウンロードし、承認されるまで使わない |
| その他 | 厳しい CSP（外部通信を禁止）、ユーザー入力は `textContent` のみで表示（XSS 対策）、iframe 埋め込みの拒否、複数タブで同時に編集しても上書きで消えない |

初版（PBKDF2）で作った保管庫やファイルもそのまま開けます。ロック解除時に自動で Argon2id に移行します。

マスターパスワードを忘れると、**誰にも復元できません**。

### 防げないこと（正直な限界）

- **GitHub アカウントの乗っ取り**：アプリは GitHub Pages から配信されます。更新の承認制で「アプリ本体の差し替え」はすぐには効きませんが、`sw.js` 自体を書き換えられるとブラウザの仕組み上いずれ読み込まれます。**GitHub アカウントの 2 段階認証は必須**です。
- **心当たりのない更新**：更新バナーに表示されるコミットが自分の変更でなければ、「更新する」を押さずに GitHub を確認してください。
- **ブラウザがキャッシュを消した場合**は、その時点の最新版をサーバーから読み込みます。
- **第三者の監査は受けていません**。銀行やメインのメールなどは、監査済みの管理アプリとの併用をおすすめします。
- **端末自体のマルウェア**やキーロガーは防げません（どの管理アプリでも同じ）。
- **フィッシングサイトの判別**はできません（自動入力ではなくコピー＆貼り付けのため）。貼り付ける前に URL を確認してください。

## Windows / Mac 用「ファイル版」（サーバーに一切つながらない）

アプリ全体を HTML ファイル1つにまとめた版です。一度ダウンロードすれば、その後は GitHub やサーバーが乗っ取られても影響を受けません。

1. ウェブ版の ⚙︎ →「PC用のファイル版をダウンロード」
   （または https://kizunajamjam.github.io/kizupass/kizupass-offline.html を保存）
2. 必要なら改ざんされていないか確認：同じ場所の `kizupass-offline.html.sha256` の値と比べる
   - Windows: `certutil -hashfile kizupass-offline.html SHA256`
   - Mac: `shasum -a 256 kizupass-offline.html`
3. ファイルを好きな場所に置き、ダブルクリックで開く（**Chrome / Edge 推奨**）。ブックマークしておくと便利です。

- CSP で**すべての通信を禁止**しています（`default-src 'none'`）。コードに不具合があっても外部へ送信できません。
- データはそのブラウザの中に保存されます。同期・バックアップは、ウェブ版と同じ暗号化ファイルで行います（ファイル形式は共通）。
- Chrome / Edge では書き出し時に保存先を選べるので、iCloud Drive のフォルダに直接保存できます。
- 自動では更新されません。新しい版を使いたいときは、もう一度ダウンロードしてください。
- iPhone ではファイル版は動かないため、ウェブ版（ホーム画面に追加）を使います。

## 端末間の同期（暗号化ファイル経由）

サーバーを使わず、暗号化済みのファイルを iCloud Drive に置いて受け渡します。
iCloud Drive は iPhone・Mac に標準で入っていて、Windows でも「iCloud for Windows」で使えます。

1. 端末A：⚙︎ →「暗号化ファイルを書き出す」→ iCloud Drive に保存
   （iPhone では共有シートの「"ファイル"に保存」を選びます）
2. 端末B：⚙︎ →「ファイルを読み込んでマージ」→ そのファイルを選ぶ

マージでは、同じ項目は**更新日時が新しい方**を採用します。削除した項目も相手側に伝わります。
新しい端末で使い始めるときは、最初の画面の「バックアップファイルから始める」を選びます。

ファイルは暗号化されているので、クラウドに置いてもマスターパスワードがなければ中身は読めません。

## Apple の「パスワード」/ Google Chrome へ移す

⚙︎ →「他のパスワード管理へ移す」から、それぞれが読み込める CSV を書き出せます（列は各アプリ自身の書き出し形式と同じ）。

- **Apple の「パスワード」**：Mac の「パスワード」アプリ →「ファイル」→「パスワードを読み込む」。iPhone（iOS 18.2 以降）は「設定」→「アプリ」→「Safari」→「読み込む」。
- **Google Chrome**：パソコンの Chrome で `chrome://password-manager/settings` →「パスワードをインポート」。

注意：

- CSV は**暗号化されません**。書き出し前にマスターパスワードで本人確認をします。読み込んだら、ゴミ箱も含めてすぐに削除してください。
- URL が登録されていない項目は読み込み先で受け付けられないため、書き出さずに一覧で知らせます。
- Excel などで開かないでください（中身が書き換わったり、意図しない動作をすることがあります）。

## 公開（無料ホスティング）

HTTPS で配信する必要があります（Web Crypto と Service Worker の要件）。

- **GitHub Pages**（このリポジトリで使用中）：Settings → Pages → Source を「GitHub Actions」にします。
  以後 `main` に push するたびに、テストが通れば `.github/workflows/pages.yml` が自動で公開します。
  公開時に `version.json` へコミット番号とメッセージが書き込まれ、各端末では ⚙︎ →「更新を確認」またはロック解除時に更新バナーとして表示されます。
  公開URL: https://kizunajamjam.github.io/kizupass/
  無料プランでは**公開リポジトリ**でのみ使えます。コードが公開されてもパスワードのデータはリポジトリに含まれないので、安全性は変わりません。
- **Cloudflare Pages**：非公開リポジトリのまま無料で公開できます。ビルドコマンドは空、出力ディレクトリは `/` にします。

## 各端末へのインストール

- **iPhone**：Safari で URL を開く → 共有ボタン →「ホーム画面に追加」。
  ホーム画面に追加しないと、Safari がしばらく使わなかったサイトのデータを消すことがあります。
- **Mac**：Safari の「ファイル」→「Dock に追加」、または Chrome / Edge のアドレスバーのインストールボタン。
- **Windows**：Edge / Chrome のアドレスバーのインストールボタン。

> 端末ごと・ブラウザごとにデータは別々です。定期的に書き出して同期・バックアップしてください。

## 開発

```sh
npm test        # 暗号化・マージ・生成・ファイル版ビルドのテスト（Node.js 20 以上）
npm start       # http://localhost:8080 で起動
npm run build:offline   # dist/kizupass-offline.html を作る
```

配信するファイルを追加・削除したら、`version.json` の `assets` も更新してください（テストで存在を確認しています）。

### 同梱ライブラリの更新手順

```sh
npm pack hash-wasm@<版>            # npm の integrity 値と一致することを確認
tar xzf hash-wasm-<版>.tgz
cp package/dist/argon2.umd.min.js js/vendor/
sha256sum js/vendor/argon2.umd.min.js  # tests/vendor.test.mjs の値を更新
```

Argon2id の計算結果は、参照実装（argon2-cffi）と同じ値になることをテストで確認しています。
